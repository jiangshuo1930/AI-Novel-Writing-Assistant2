## 修复 deslop_bridge 中文名映射失效

- 病根：`TYPE_CN` 用 `repeat` / `adjacent-repeat` / `truncation` / `placeholder` 做键，
  而 `check-degeneration.js` 实际产出 `verbatim-repeat` / `truncated` / `placeholder-leak`，
  退化类告警的中文名全部落空、回退成英文 type。
- 改法：键改成 JS 字面量；`verbatim-repeat` 按 message 前缀（逐行复读 / 长句复读）
  用 `SUBTYPE_CN` 细分成「紧邻整行重复」「长句复读」；`_label()` 负责取值。
- 防回归：新增 `type_drift()` 扫 JS 源码里的 `type: 'xxx'` 字面量，比对 `TYPE_CN` 覆盖，
  返回 missing / stale；`deslop_bridge.py --types` 可直接跑；`test_deslop.py` 增加映射自检段
  （总数从 23 条变 24 条，仍全绿）。
- 结论：`test_deslop.py` 24/24，第一章回归仍硬伤 0、待看 1。
