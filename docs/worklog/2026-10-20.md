## 接上原版第 8 步：结构自检（rubric 五组 + selfcheck L2–L4）

两张表分工必须分开，否则「每章都要过」会被 29 项诊断表撑成不可能：

- **rubric.md（五组 29 项）= 体检表**：原文「分五组看，一次只看一组」，判 fail 只记 advisory；
- **selfcheck.md 的 L2 / L3-1 / L3-2 / L4 = 交付门槛**：fail 即 blocking；
- **L1 不交模型判**：破折号、禁用词、套话、引号已由机械门逐条清零。

流程：机械门 `blockingCount === 0` 后跑自检 → 失败项合并成 `blockingIssues` 与 `[sepia 自检 L4-2] …` 修文指令 → 修完复跑，两级门都清零才算过。自检没跑成（LLM 故障）只打 `sepia_selfcheck_unavailable` 不阻断；机械门没跑成仍按未过门算。

- 新 prompt `novel.sepia.structural_self_check@v1`，数据全由规则包注入，不含硬编码阈值。
- 自检按 `contentHash + packVersion + model` 缓存，重跑验收不重复烧 token。
- 新增 `quality.sepia_selfcheck_failed`（locked 暂停）、`SEPIA_SELFCHECK_DISABLED` 开关（独立于 `SEPIA_DISABLED`）。
- 编辑器卡片增一行「上次结构自检：通过 / 未过 N 项 / 诊断 M 项」。
