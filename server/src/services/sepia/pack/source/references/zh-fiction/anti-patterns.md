# 反例库（只看，别照抄）

这里全是**错的写法**。写的时候照着 `techniques.md` 抄，不要照这一页抄。

这一页的用途有两个：① 训练眼睛，认出毛病；② 自检时对照，看自己是不是也这么写了。

标 `[L1]` 的表示它同时违反自检清单里的某一项，是硬伤。

---

## 一、情绪标签（`[L1-10]`）

| 反例 | 错在哪 |
|---|---|
| 他很生气 | 直接说情绪，读者不用感受 |
| 她感到一阵委屈 | 同上，还加了量词撑字数 |
| 他心中涌起复杂的情绪 | 最典型的机器句，等于什么都没说 |
| 她心里五味杂陈 | 四字成语替代具体感受 |
| 他内心深处其实很在意 | 作者替读者下结论 |
| 她意识到事情不对劲 | "意识到"是心理揭示的标准套 |
| 他明白了一切 | 同上，而且偷懒 |

## 二、模板体感（`[L1-2]`）

| 反例 | 错在哪 |
|---|---|
| 攥到指节发白 | 悬疑文最烂大街的一招，两处以上就是模板 |
| 指尖泛白 | 同上 |
| 后背发凉 | 万能恐惧标签 |
| 心跳如鼓 / 心跳漏了一拍 | 紧张三件套 |
| 呼吸一窒 / 忘了呼吸 | 恐惧=呼吸异常，思维定式 |
| 手脚发抖 / 双腿发软 / 身体一晃 | 恐惧标准动作包 |
| 后颈汗毛竖起 | 第六感的标准写法 |
| 头皮发麻 | 万能收尾 |
| 指甲嵌进掌心 | "攥"的变体 |
| 她狠狠地攥紧了拳头 | 愤怒的标准配平 |

> **怎么替代**：换成不那么标准的动作。有人紧张时反复清嗓子，有人不停摸耳垂，有人站得更直，有人不停眨眼。

## 三、氛围三件套（`[L1-2]`）

| 反例 | 错在哪 |
|---|---|
| 空气仿佛凝固了 | 悬疑、情感类的万能句 |
| 一片死寂 | 同上 |
| 安静得可怕 | 同上，还带叙述者评论 |
| 空气中弥漫着一股诡异的气息 | 两个毛病叠一起 |
| 时间仿佛静止了 | 万能抒情 |

> **怎么替代**：写具体的声音。空调停了。冰箱也没响。连楼下的狗都不叫了。

## 四、句式套子（`[L1-9]`）

| 反例 | 错在哪 |
|---|---|
| 不是A，而是B（一段里出现三次以上） | 最典型的机器骨架 |
| 他不需要X，他只需要Y | 对称哲理句 |
| 那一刻，他终于明白了什么 | 心理揭示的标配开头 |
| 他/她不知道的是…… | 铺伏笔最偷懒的方式 |
| 她沉默了片刻 / 顿了几秒 / 良久 | 对话停顿的统一模板 |
| 他的眼神闪过一丝复杂 | "闪过一丝"是小说圈最臭名昭著的一句 |
| 他的目光平静如水 | 用"目光"代替写动作 |
| 他深吸一口气，然后说 | 准备做事的标准动作 |
| 她的心提到了嗓子眼 | 紧张标配 |
| 说不上来 / 难以形容 / 难以名状 | 写不出情绪就写"说不出" |
| 一股莫名的情绪 | 用"莫名"糊弄 |
| 没来由地感到一阵不安 | 同上，还叠加了"一阵" |
| 不禁 / 不由得 / 忍不住 | 人物不需要这三个词 |
| 下意识地后退一步 | 同上 |
| 带着一丝笑意 / 带着几分无奈 | 状语堆砌 |
| 像被抽空了力气 | 陈词滥调比喻 |
| 仿佛天塌下来一般 | 同上，还带夸张 |

## 五、书面连接词（`[L1-2]`）

`然而`、`因此`、`此外`、`似乎`、`显然`、`或许`、`于是乎`、`紧接着`、`随后`、`与此同时`

> 这些词本身不算错，**密度高**才是问题。一段里出现两个以上，就该换掉一个。换的时候别全换成同一个替代词——那会变成新的指纹。

## 六、开篇的三种死法（`[L1-7]` `[L1-8]`）

1. **天气景物起手**："平城的风跟刀子似的。"开篇比喻是最高命中的 tell。
2. **镜头式交代**："他竖起衣领，拍了拍身上的尘土，抬眼望向远方。"这是用一个干净的小动作来交代环境，标准的机器开场。
3. **教科书背景**："在大衍王朝的第三百年，天下分为七国……"设定倾倒。

> **正确开法**：直接进人物当下的状态、内心碎念、一句对话，或一件正在做的事。环境靠后文自然带出。

## 七、道具模板（出现两个以上就要换掉一半）

| 模板道具 | 机器的用法 |
|---|---|
| 监控摄像头 / 录像回放 | "回放里拍到了不该出现的东西" |
| U 盘 | "里面存着秘密文件" |
| 旧相册 / 老照片 | "翻到一张褪色的照片，揭开往事" |
| 钥匙 | "一把不知道开哪扇门的钥匙" |
| 拖鞋 / 门口的鞋 | "门口多了一双鞋" |
| 秒表 / 计时器 | 用来量化异常 |
| 手写纸条 / 匿名信 | "收到一张纸条" |
| 百度街景 / 地图年份 | "翻历史街景发现……" |

> **原则**：道具必须长在这个故事里。同样的道具能无缝换到另一个故事，它就是模板。

## 八、结构反例（`[rubric 第一/三组]`）

| 反例 | 错在哪 |
|---|---|
| 结尾一段"他终于明白，人这一辈子……" | 作者跳出来总结 |
| 主角查案，线索一二三依次到手，最后真相大白 | 因果链一条直线，没有岔子 |
| 每章都是努力→成功→释然 | 结局太圆，读者会腻 |
| 反派孤身一人，专门跟主角作对 | 反派没有自己的生活 |
| "其实当年的事是这样的……"后接三百字 | 信息直塞 |
| 所有伏笔在最后一章精准回收 | 零废料，AI 记账癖 |

## 自检用法

写完一章，用 `scripts/lint.py` 先跑机械项（破折号、禁用词、引号、句号密度），再拿这一页对照**结构**和**句式**两类——那两类脚本抓不到，只能眼看。

对照的时候只问一句：**我是不是也这么写了？** 是，就改。
