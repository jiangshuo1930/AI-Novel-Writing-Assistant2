# 禁用词清单 + AI 模板句式清洗表

通用 AI 高频词 + AI 模板句式 + 小说专属模板句式黑名单，三层合并。L1 硬性清零时按本表扫描；本表同时是 `scripts/lint.py` 的词表来源，改这里等于改脚本。

---

## 一、机械连接词 + AI腔副词（命中即换）

```
仿佛|犹如|一丝|微微|轻轻|淡淡|然而|因此|此外|似乎|宛如|俨然|堪称|显然|或许|可见|折射|彰显|蕴含|弥漫|萦绕|勾勒|跃然|浮现|毋庸|不言而喻|顾名思义|独具|别具|引人|叹为|波澜|惊心|刻骨|魂牵|心旷|流连|耐人|发人|瞩目|遐迩|皆知|耳熟|如雷|忽然|猛地|骤然|恰好|分明|俨然
```

**替换方向**：把抽象/书面词换成具体动作或口语。
- 忽然 → 冷不丁/突然/一下
- 微微 → 低了低头
- 轻轻 → 踢了踢
- 分明 → 摆明
- 俨然 → 活像个
- 似乎 → 八成/看着像
- 然而 → 可/但
- 因此 → 就/所以
- 仿佛/犹如 → 删掉，直接写本体

## 三、通用AI词汇清洗表

| AI词/句式 | 替换为 |
|:----------|:------|
| 随着……的发展/在……背景下 | 直接删掉这句 |
| 值得注意的是/值得一提的是 | 删掉，或改为"关键是什么？" |
| 在一定程度上/从某种程度上说 | 删掉 |
| 赋能、重构、重塑、破局、深耕、布局 | 换成具体动作 |
| 闭环、护城河、壁垒、赛道、格局 | 换成大白话 |
| 显著、深入、全面、系统、核心、关键 | 删除，或用数据说话 |
| 进一步、持续、不断、日益 | 删除 |
| 标志着、意味着、彰显了、体现了 | 直接说"是"或陈述事实 |
| 打造、构建、实现、形成 | 换成"做""有""成" |
| 总而言之/综上所述/概括而言 | 删除 |
| 首先…其次…再次…最后… | 打破顺序，用"还有""对了"重新串联 |
| 以下将从X个维度展开 | 删除 |
| 展望未来/我们有理由相信 | 删除，结尾留一句判断 |
| 至关重要/不可或缺/举足轻重 | 删掉 |
| 在……方面表现突出/具有优势 | 直接说"做得好""比……强" |
| 基于/依托/凭借 | "靠" |

## 四、AI模板句式清洗表（整句模式，发现即拆解重写）

| AI模板句式 | 为什么是AI | 怎么拆 |
|:-----------|:---------|:------|
| 不是XX，而是YY | AI最爱对比句式，一篇出现三次以上就是铁证 | 拆成两句独立短句，或删掉"不是XX"直接说"是YY" |
| 那一刻，他/她意识到…… | AI标配心理揭示句，人物不需要"意识到"——让他做出来 | 删掉"意识到"，直接写人物做了什么 |
| 眼中闪过一丝…… | 小说圈最恶名昭彰的AI句式 | 整句删除，换具体的身体动作或对话 |
| 心中涌起…… / 内心深处…… | AI情绪万能句式，空洞且模板化 | 删除，用身体反应代替（技法16） |
| 不由得/不禁/忍不住…… | 人物不需要"不由得"，读者自己能判断 | 删除"不由得/不禁/忍不住"，直接写后面的动作 |
| XX，仿佛/似乎/好像…… | 单个还好，一篇超过3个就是AI在凑比喻 | 超过3个的砍掉一半；保留最独特那个 |
| 在……的背景下 / 随着……的发展 | AI开篇万能模板 | 直接删除整句，从第二句开始 |
| 首先…其次…再次…最后… | AI结构化列举的铁证 | 打破编号，用"还有""对了""另外"串联 |
| 不仅……更…… / 既……又…… | AI的"全面覆盖"强迫症 | 拆成两句，或只说一半留一半给读者 |
| XX是YY的ZZ / XX意味着YY | AI的定义癖——总想给事物下定义 | 直接陈述事实，不下定义 |
| 空气中弥漫着…… / 空气仿佛凝固了 | 悬疑/情感类AI高度复用句 | 换成具体的环境描写或人物感受 |
| 他/她深吸一口气…… | AI写人物"准备做某事"的标准动作 | 删除，直接写后续动作 |
| 说不上来 / 难以形容 / 难以名状 | AI偷懒——写不出情绪就写「说不出」 | 删掉。写人物做了什么来回避描述这种感受 |
| 心里涌起…… / 一股莫名的…… / 没来由地…… | AI情绪万能引入——用「莫名」糊弄 | 删除。让读者从上下文自己感受到那种情绪 |
| 她/他突然意识到…… / 她/他终于明白…… | AI标配心理揭示句 | 删除「意识到/明白」，直接写人物做了什么或说了什么 |
| 顿了几秒 / 沉默片刻 / 半晌 / 良久 | AI写对话停顿的统一模板 | 用动作填充停顿：他把烟掐了。又点了一根。她拿起杯子，喝了一口已经凉掉的水 |

## 五、小说专属模板句式黑名单（出现即高度可疑）

### 万能情绪描写（AI最爱批量堆砌）
| 模板句式 | 为什么像AI | 重写方向 |
|:--------|:---------|:--------|
| 指尖泛白 / 指节泛白 | 悬疑AI标配生理反应，一篇出现两次以上就是模板堆砌 | 换成只有这个人物会做的特定动作——有人紧张时反复清嗓子，有人不停摸耳垂 |
| 手心发凉 / 后背发凉 / 后背发热 | 万能"恐惧"标签 | 用环境反衬：她没觉得冷，但她发现自己的手指在抖 |
| 心跳轰鸣 / 心跳如鼓 / 心跳漏了一拍 | AI标配紧张反应三件套 | 用身体细节：她把手机翻过来扣在桌上。又翻回来。 |
| 手脚发抖 / 双腿发软 / 身体一晃 | AI恐惧标准动作包 | 换成非标准动作——有人恐惧时站得更直、有人不停眨眼 |
| 指尖攥紧 / 指节攥得发白 / 指甲嵌进掌心 | 「攥」是AI写恐惧最爱的动词 | 换。有人恐惧时反复揉衣角、有人不停转手上的戒指 |
| 呼吸停滞 / 呼吸一窒 / 忘了呼吸 / 喘不上气 | AI标配——恐惧=呼吸异常 | 删掉。恐惧时呼吸的变化读者身体会自己同步 |
| 后颈汗毛竖起 | AI的"第六感"标准写法 | 删掉。让人物注意到一个具体的异常细节 |
| 空气凝固 / 一片死寂 / 安静得可怕 | 悬疑AI氛围三件套 | 写具体的声音：空调停了。冰箱也没响。连楼下的狗都不叫了。 |
| 心提到了嗓子眼 | AI标配紧张反应 | 删。换成具体的动作——她把包抱在胸前，一直没放开 |
| 脑海中闪过 / 脑海里浮现 | AI式回忆引入标准句式 | 直接切入回忆画面，不需要"脑海中闪过"做桥梁 |
| 头皮发麻 / 脊背发凉 | AI恐惧万能收尾句 | 删。如果前面的描写够到位，读者自己会头皮发麻 |
| 「动词+宾语，动词+宾语，动词+宾语」连续三个以上的逗号动作罗列 | AI动作描写底层结构签名 | 按人物情绪状态处理：冷静日常可保留；恐惧/紧张/疲惫时必须拆成句号断句 |

### 叙事句式
| 模板句式 | 为什么像AI | 重写方向 |
|:--------|:---------|:--------|
| 不是XX，而是YY | 对比句式在一篇中反复复用是AI铁证 | 拆成两句独立短句，或删掉前半直接说"是YY" |
| 那一刻，他/她意识到…… | AI标配心理揭示句 | 删掉"意识到"，让人物做点什么来体现这个领悟 |
| 他/她不知道的是…… | AI铺设伏笔的最偷懒方式 | 用具体的暗示代替。让读者自己发现"有什么不对" |
| 沉默了几秒 / 顿了几秒 / 良久 | AI写对话停顿的统一模板 | 用动作填充停顿：他把烟掐了。又点了一根。 |
| XX的目光/眼神…… | AI赋予人物"神情"的最偷懒方式（目光平静、眼神复杂、目光闪烁） | 删掉。写人物的手在干什么——手比眼神诚实 |
| 所有伏笔在结尾精准回收、每条线索都导向同一个真相 | AI「零废料」叙事 | 保留1-2条不回收的支线；加入主角猜错的方向；让某些细节纯粹因为「生活里存在」而存在 |

## 六、小说AI模板道具清单（出现即警惕，两个以上确认模板化）

| 模板道具 | AI的用法 | 替换思路 |
|:--------|:--------|:--------|
| 监控摄像头 | "发现了监控里拍到了不该出现的东西" | 换成只有这个场景才会有的观察方式——邻居老太太的买菜路线、保安的交班时间 |
| U盘 | "里面存着秘密文件" | 换成只有这个职业/年代才会用的存储方式——速写本、病历、旧手机备忘录、账本夹页 |
| 旧相册/老照片 | "翻到一张褪色的照片，揭开了往事" | 换成具体的、有感官细节的记忆载体——一件起球的毛衣、一盒过期的药、一张超市小票 |
| 手机（老式手机） | "里面有一条没有发送的短信" | 手机可以用，但内容不能是模板——不是"未发送的短信"，是某个人反复打又反复删的草稿 |
| 钥匙 | "一把不知道开哪扇门的钥匙" | 太老套了。换。 |
| 拖鞋/鞋子 | "门口多了一双/少了一双鞋" | 换。改成只有这个人物会注意到的东西——冰箱里少了一罐啤酒、洗衣机里的衣服不是他的 |
| 餐桌/晚餐 | "餐桌上的沉默/三人晚餐" | 餐桌可以用，但把重点从"沉默的氛围"转移到具体的、奇怪的动作上 |
| 秒表/计时器/闹钟 | 主角用它「量化异常」 | 换成体感。不写「电梯用了47秒」，写「电梯门关上之后，她感觉过了很久」 |
| 旧报纸/微缩胶片 | 「在档案馆翻到一条旧新闻」 | 信息不能靠「翻到」获取——打碎成多人的只言片语 |
| 电梯面板/楼层按钮 | 「按钮磨损程度不一样」 | 换。换成只有这栋楼/这个职业才会注意的空间异常 |
| 监控截图/录像回放 | 「回放监控发现……」 | AI最爱的信息直塞方式。换成女主自己注意到的、无法截图的生活细节 |
| 手写纸条/匿名信 | 「收到一张纸条」 | 太偷懒了。关键线索不能从天而降 |
| 百度街景/地图年份 | 「翻百度街景历史年份」 | 换成不经意的日常发现——不是主动去搜，是偶然注意到 |

**核心原则**：道具必须长在这个故事里。如果同样的道具可以无缝换到另一个故事——它就是模板道具。

## 使用说明

- Step 4 L1硬性清零时，按本表逐项扫描
- 禁用词用 Grep 工具全文搜索，命中即换
- 模板句式需人工判断语境，不能机械替换（部分句式人类也偶用，看密度）
- 道具清单不是禁用，是"警惕"——出现两个以上要换掉一半
