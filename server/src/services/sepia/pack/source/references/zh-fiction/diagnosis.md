# 诊断框架

改写前先用本框架扫描原文。四维诊断 + 朱雀六特征 + 五维风险 + 强/中/弱信号库，小说向裁剪。

## 一、四维诊断（语言/叙事/细节/设定）

### 改前必问的五个基础问题
1. 句式是乱的吗？有没有连续3句以上长度/结构相近？
2. 读完之后，有哪句话你记住了？还是全程流畅但一片空白？
3. 人物/作者有矛盾、有糊涂、有前言不搭后语吗？还是全员清醒通透？
4. 细节是私人专属记忆，还是网络通用素材？（监控、U盘、旧相册、钥匙、拖鞋——出现两个以上就要警惕）
5. 如果铺了悬念，圆的了吗？还是靠"开放式结局"掩盖逻辑漏洞？

### 悬疑/叙事类扩展十问
6. 关键信息是怎么交代的？「一个人物坐下来一次性讲清楚」还是「散落在日常细节里由读者自己拼」？
7. 有没有读到任何一处「这个细节写来干嘛？」的瞬间？没有 → 太干净了，每个字都在为情节服务 → AI
8. 出现的数字是「大概/差不多」还是「23秒/47秒/30公分」？精确数字制造诡异感 → AI无疑
9. 人物是善恶二元切割吗？有没有100%纯良或100%纯恶的角色？
10. 主角推理有没有走过弯路？有没有误判过、漏掉过、推翻过自己的结论？
11. 超自然现象的触发规则有没有用主角个人历史做铺垫？换一个主角，这套规则还能成立吗？
12. 恐惧场景中的感官信号是通用恐怖符号（樟脑/灯光闪烁/后背发凉），还是与人物私人创伤绑定的独有信号？
13. 伏笔是否存在「零废料」现象？所有线索是否都在结尾精准回收、无一浪费？有没有至少1个看似有深意但最终未揭晓的「干扰项」？
14. 人物疲惫/恐惧/激动时，句子有没有跟着破碎？还是始终保持着「动词+宾语，动词+宾语」的工整并列结构？
15. 感官描写是正确但不讲道理的吗？有没有一处嗅觉/触觉联想是只有这个人物才会产生的、跳跃的、带有「个人偏见」的？

## 二、四维病灶清单

### 语言层病灶
- AI模板句式：「指尖泛白」「空气凝固」「不是XX，而是XX」「那一刻，他/她意识到……」「眼中闪过一丝……」
- 通用AI高频词：仿佛/犹如/一丝/微微/轻轻/淡淡/然而/因此/此外/似乎/宛如/俨然/显然/或许
- 恐惧生理反应万能模板包：后背发热、心跳轰鸣、手脚发抖、身体一晃、呼吸停滞
- 语言过于顺滑：通篇无碎口语/突兀短句/半截想法
- 连续「动词+宾语，动词+宾语」逗号并列罗列（如「她把钥匙插进锁孔，拧了两圈，开门，进去，关门，反锁」）
- 人物疲惫/恐惧/激动时句子仍工整，未随情绪破碎

### 叙事层病灶
- 人物过于通透：异常冷静理智、自我剖析精准如心理导师
- 只造「细思极恐」氛围但放弃因果链
- 八篇同一个叙事框架（日常→怪事→线索→对峙→开放结尾）
- 关键信息靠口述/文档/截图/搜索一次性直塞
- 用精确数字制造诡异感（23秒/47秒）
- 人物行为不符合真实人性（发现异常后第一反应是搬家还是买闹钟做实验）
- **主角推理全程零失误**：每条线索都精准命中、从不误判、从不走弯路——AI全知视角底层痕迹
- **人物善恶二元切割**：主角团全员好人、反派团全员坏人——AI安全性训练痕迹
- **超自然规则空降**：只展示结果，没有用主角个人历史/旧物件/记忆做隐性铺垫
- **伏笔零废料回收**：所有线索都在结尾精准回收、无一浪费，无「干扰项」

### 细节层病灶
- 意象道具通用模板：监控、U盘、手机、旧相册——出现两个以上即可确认模板化
- 情绪靠"他很愤怒""她很害怕"贴标签
- 道具100%功能化（全部道具都在服务情节），无「闲笔」
- 恐惧感官标准化恐怖符号（樟脑呛人、灯光闪烁、后背发凉），无记忆闪回
- 感官描写准确但通用，无个人偏见（"樟脑丸混着旧棉絮"对得太标准了）

### 设定层病灶
- 原文声称多位作者/多角色视角，文风却完全统一
- 主角踩了「数据/会计/分析师/数字控」模板
- 空间恐怖缝合了「违建楼层/电梯夹层/甲虫象征灵体」

## 三、朱雀六特征（要躲的敌人）

1. **低熵/模式化**：每句长度结构雷同，节奏像机器
2. **N-gram/困惑度统计指纹**：用词分布过于"标准中文"，缺个人化语料
3. **机械逻辑连接词**：然而/因此/此外/显然/或许 这类书面连接词密集
4. **段落过工整**：每段都起承转合、信息密度均匀、没有"废笔"
5. **缺个人化表达**：没有"这个人特有的嗓音"——不骂人、不走神、不犯错
6. **动态阈值**：创意小说阈值偏低（约0.5），比议论文/说明文更容易被判AI

## 四、五维风险扫描（小说向适配）

| 维度 | 高风险表现 | 处理方向 |
|---|---|---|
| **词语可预测性** | 句子后半截几乎能猜出来；"标准答案式"词组收束；抽象词高密度 | 用具体事实代替抽象判断；把"正确但空"换成作者嘴上会说的话 |
| **句长方差** | 每句话长度接近；段落大小整齐；全文像模板填空 | 插入1-5字短句；保留带插入语的长句；拆掉连续排比 |
| **语义过连贯** | 每段紧扣主题，无停顿/回想/转念；"首先其次最后"串完整篇；每个论点解释得太满 | 加入轻微思维漂移（先说相关感受/弯路/迟疑再拉回）；保留真实的"我一开始想错了" |
| **模板特征词** | 书面连接词、套话、宏大形容词集中；段落开头像批量生成 | 全文搜索模板词密度高的优先删，不机械替换；用口语动作替代书面连接 |
| **词概率分布** | 全文一直选"安全词""高概率词"；语气稳定礼貌完整无个人偏差 | 加入作者偏好、判断边界、具体对象；允许少量"不标准但准确"的表达 |

## 五、信号强度分级（必改 / 看密度 / 看叠加）

### 强信号特征（必须处理）
- **"不是X是Y"高密度**：800字内出现3次以上 → 保留1次，其余改直接判断或疑问句+短句
- **段段金句收束**：连续3段都有收束金句（"这才是……""这就是……"）→ 只让最重要的1-2段有金句
- **开头三件套**：前3句话"钩子+痛点+承诺"结构 → 从你真正想让读者知道的那件事开始

### 中信号特征（密度高时处理）
- **同一让步模板**：同一篇出现3次以上"虽然……但是……" → 保留1次，其他换说法
- **连接词固定位置**：段首高频出现"然而""事实上""值得注意的是" → 删掉一半
- **翻译腔**：高频出现"作为""基于""进行""关于" → 改成嘴上会说的话

### 弱信号特征（叠加时处理）
- **命名仪式**：同一篇出现2次以上"我把它叫做……" → 只留1次
- **同义词刻意替换**：同一段换3个以上词说同一件事 → 如果这个词准确，重复用
- **对"深刻"的过拟合**：出现"本质上""归根结底"且后面接了比前文大一号的命题 → 删掉升维句

## 诊断输出要求

扫描后标记每维的具体病灶（数量+位置），用于 Step 2 定档分级和 Step 3 改写。诊断要具体到"哪一句、哪一段"，不要泛泛而谈"语言层有问题"。
