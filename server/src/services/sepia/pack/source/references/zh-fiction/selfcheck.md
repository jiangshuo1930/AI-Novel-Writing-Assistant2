# L1–L4 自检清单 + 误伤警告 + 诊断分级

分层自检纪律 + 误伤警告。交付前必须逐项逐条核查，不许跳。

> 路径说明：本文件在 `references/zh-fiction/`，同目录直接写文件名即可（`banned-words.md` / `techniques.md`）；跨目录用相对路径（`../narrative-pass.md`）。检查顺序三层不变：架构（narrative / discourse）→ 表面（style-surface + zh-fiction）。

---

## 诊断分级（Step 2 定档，动笔前先量体裁衣）

扫完病灶后，按以下指标给文本定档。取最高档位，任一达重度即按重度处理；无重度时中度≥3项按中度。

| 指标 | 轻度 | 中度 | 重度 |
|------|------|------|------|
| 禁用词密度（/千字） | ≤5 | 6-15 | >15 |
| 连续排比段数 | ≤2 | 3-4 | ≥5 |
| 心理词占比（觉得/认为/感到） | ≤10% | 10-25% | >25% |
| 对话标签密度（"说/道"占比） | ≤30% | 30-50% | >50% |
| 平均段落句数 | ≤3 | 3-5 | >5 |
| 连续同长句数（相邻≥3句长度接近） | ≤2 | 3-4 | ≥5 |
| 对话占比（场景章带引号直接对话） | ≥30% | 20-30% | <20% |

**处理力度**：
- 轻度 → 仅做去泛化（禁用词替换、心理外化、排比打断）
- 中度 → 去泛化 + 去书面化（句式去套路、连接词精简、修饰清扫）
- 重度 → 完整三遍 + 重点段落重写（含技法9-12的故意打破与断裂 + 内容注入技法）

**心理词外化**：“他很紧张”→“他的手在抖”；“她觉得委屈”→“她把嘴抿紧了”。
**修饰清扫**：一次只用一个形容词，不连用不堆砌。“惨白的月光”→“月光”；“微微颤抖的手指”→“手指在抖”。

## L1 硬性校验（交付前必须过，任何一项不通过必须修复）

### L1-1 破折号（——）清零
零容忍。用逗号或句号代替。（朱雀模式化信号 + 用户硬规则）

### L1-2 机械连接词/禁用词清零
清单见 `zh-fiction/banned-words.md`。命中即换。
**换法不重复**：同一禁用词多处出现时，每处替换写法不能雷同——防止替代词成为新指纹（实测踩坑："忽然"全卷换"冷不丁"13 处，替代词本身变新指纹被朱雀命中）。热门替代词（冷不丁/莫名/到底/没来由/一下）改完后再全卷 grep 复查一次密度。

### L1-3 结构性套话扫描清零
以下套路出现即改：
- “让我们来看看”“在当今……的时代”“众所周知”“毋庸置疑”
- 连续 bullet point 罗列、大段加粗罗列（小说正文禁用）
- “不是 A 而是 B”否定排比 → 直接写 B
- “带着……”状语堆砌（带着一丝……带着几分……）→ 拆成动作

### L1-4 空泛概括扫描清零
无“意义重大”“作用关键”“不言而喻”类空话；知识点不靠"下面我来科普"抛出，靠角色聊着聊着顺手掏出。

### L1-5 对话引号统一全角弯引号“”（直角与半角清零）
交付稿对话一律用 `“”` 全角弯引号（内部嵌套用 `‘’`），**直角引号（U+300C / U+300D）与半角双引号 `""`、英文引号 `"` 清零**。
理由：半角 `"` 是模型默认输出、最容易被机械识别的信号，必须清零；全角弯引号与直角引号二选一，本包统一取 `“”`——`scripts/lint.py` 的 L1-5 以 `“”` 成对为通过标准，出现直角即计为异常。

### L1-6 冒号（：）精简
尽量改逗号/句号，避免"定义式"工整。"他唯一确定的是："这类解释式冒号一律打散。非硬阻断，但密度高会拉低活人感。

### L1-7 比喻克制（仅禁两类）
**不强制全清零比喻**。允许自然嵌入的感官小比喻（"像两颗泡在水里的黑豆""手抖得像刚攥完一把冰"），这类增人味。**仅禁两类**：
1. **开篇天气/景物比喻**：“平城的风跟刀子似的”“碑像两列哑了的兵”是朱雀最高命中 tell。开篇一律白描或直接从内心/琐事/对话切入
2. **陈词滥调比喻**：“如沐春风”“梨花带雨”“像一块石头”“心像被揪住”→ 改具体动作或白描

### L1-8 开头禁用"镜头式建立场景"（AI模板）
章节/段落开头不写“角色做某个小动作来交代环境”的干净镜头——竖领子、拍尘土、深吸一口气、抬头看天、眯眼望向远方。开场应直接进**人物当下状态/内心碎念/一句对话/一件正做的事**，环境靠后文自然带出。

### L1-9 对称/排比/对比句式清零（最高命中 tell）
朱雀对中文句式骨架的"平衡感"极度敏感。一段内以下结构密度过高，AIGC值直接飙到0.7-0.8。**必须打碎**：
- 罗列排比：“道武帝怎么杀兄，怎么并吞诸部，哪场仗谁叛了谁”→ 改成散句
- 对称哲理句：“皇帝不需要杀你，只需要不回答你”“不是得意，是……”→ 删掉对称骨架，改口语直述
- 顶真/重复修辞：“抄的人多了，这史就传开了。传开了，就收不回了”→ 一句带过
- 四字工整句：“魏书修成，崔家三代侍魏，没白侍”→ 拆成口语长句
- 自检：写完扫一遍，凡读着"顺口、对仗、像格言"的句子，一律打散

### L1-10 "他知道/看出/觉得那是…"内心总结句清零
零命中“他/她知道…（某种心理或关系判断）”“他看出…”“他意识到…是…”类把角色内心状态/关系直接总结给读者的句式。真人用动作/反应展示，不替读者下结论——最高权重毒句之一。
- 改前：陈谒知道那层东西是防备，也知道她在记路。
- 改后：陈谒没吭声。她眼睛往两边扫，脚步半步跟在后面，那是被看管的人记路的本能。
- 例外：剧情性"得知道""不知道要干什么"等叙述不是此禁（仅禁"他/她知道+心理判断"的总结句）

### L1-11 角色代词一致性扫描（Agent 并行改稿后强制）
**男性角色出现"她/小姑娘/女士"即 OOC 硬伤，必须修复**。适用场景：任何由多个 Agent/子任务并行产出的章节，合并前强制全角色代词核查。
- 实测踩坑：并行产出把"小周（周浩，男实习生）"写成"她/小姑娘"共 5 处，OOC 严重
- 核查法：对全文 grep 女性代词（她/小姑娘/女士/姐），逐一对应到角色性别表（CHARACTERS.md 或大纲人物表）；拿不准就查角色档案
- 顺带对表时间线数字（入职时长/日期/年龄）跨章一致性，并行产出最容易各自为政

### L1-12 句号使用要慎重
句号不是越多越好，也不是越少越好。**删多余句号 ≠ 无脑合并**：
- 碎句堆砌（句号过密）：连续 3+ 句都是极短句、句子被切碎成"词块"——情绪高点用一两次是力量，全文如此是 AI 节奏问题
- 长句连排（句号过疏）：每句 30+ 字、句式均匀无停顿——同样被朱雀抓"句式均匀"
- 参考密度：每百字 5-8 个句号；长短交替，情绪高点短句断，冷静处可长句工整
- 自检：写完扫一遍，把"一句话被切碎"的相邻短句视节奏需要合并，把"一口气读不完"的长句在自然停顿处断开

## L2 风格一致性（模式匹配层）

- **L2-1 开头**：是否从具体、当下事件切入？第一句是否让人想"然后呢"？忌教科书开头、忌大段背景倾倒
- **L2-2 节奏与结构**：长短句是否交替？是否有一句话独立成段的"断裂"效果？是否避免了不必要的小标题/分节符号？
- **L2-3 口语化与打破**：是否有口语化表达？有没有叙事中的故意打破（技法9）？有没有至少一处自嘲或承认不足（技法12）？
- **L2-4 标点禁令二次确认**：全文是否完全没有冒号、破折号？对话是否全部 `“”` 全角弯引号、零直角与半角引号？（与 L1-5 一致）

---

## L3 内容质量（深度审查层，小说适配）

- **L3-1 细节支撑**：每个关键情节点是否有具体人/场景/动作/感官细节支撑？忌空泛过渡
- **L3-2 信息输出方式**：背景知识是否以"角色聊着聊着顺手掏出"呈现，而非"作者跳出来科普"？关键信息是否用碎玻璃法散落（技法24），而非口述/文档/截图直塞？
- **L3-3 对立面与同理心**：反派/对手是否有可理解的动机？别写成纯恶（技法17 人性灰度）
- **L3-4 逐一展示**：多线索/多人物比较时，是否逐一展示而非一次性罗列？

---

## L4 活人感终审（最终人格层）

以读者视角通读全文，问自己："读完这章，我感觉是个真人在跟我讲一个他经历/编出来的故事，还是一个AI在输出信息？"

- **L4-1 温度感**：情绪表达是身体直接反应还是比喻/知识性描述？（"风往脖子里钻，他缩了下脖子" vs "风像刀子"/"天气寒冷"）
- **L4-2 独特性**：是否有"只有这个作者/这个角色才会写出来的角度"？
- **L4-3 姿态**：语气是不是"一个有见识的普通人在认真聊"？有没有滑入"导师教学生"或"解说员播报"？
- **L4-4 心流**：从头读到尾，有没有注意力断掉、需要回头理解逻辑的地方？

## 误伤警告（不能机械判AI）

以下句式人类作者也高频使用，不能机械判定为AI味。处理时看密度，不看单次出现。

| 特征 | 触发阈值 | 说明 |
|---|---|---|
| "不是X是Y" | 800字内出现3次以上 | 鲁迅、李敖、罗翔都用。低密度是正常修辞 |
| 收束金句（"这才是…"） | 连续3段都有 | 偶尔用是正常修辞，段段都用才是AI |
| 堵住反驳（穷尽反面） | 仅适用于自媒体/社交媒体 | 学术写作和法律论证穷尽反驳是规范，不判AI |
| 命名仪式（"我把它叫做…"） | 同一篇出现2次以上同一句式 | 偶尔用一次是正常修辞 |
| 短句独立成段 | 每段都这样 | 情绪高点用一次是力量，全文都用是AI节奏问题 |
| 自然嵌入的小比喻 | — | "像两颗泡在水里的黑豆"这类增人味，允许保留（L1-7） |

**误伤处理原则**：先看密度，再看语境。人类偶用是修辞，AI是高频复用。单次出现不判，密度超标才处理。

## 通过标准

- **L1 全零**：破折号、禁用词、套话、空泛、双引号、排比、内心总结句全部清零
- **L2 取最高档对应项通过**
- **L3-1/L3-2 必须过**
- **L4 整体"像真人写的"**

任何一项觉得"AI味太重"就返工。规则清洗修不了"活人感"，该重写段落就重写，重点段用技法9-12打破 + 内容注入技法换骨。

## 双测试（收尾强制，见 `../style-surface.md` 第三节，克制"注入过头"）

跑完上面 L1–L4 后，**再跑两个编辑痕迹测试**——专门克制"加人味加过头"的倾向：

- **删除测试（deletion test）**：对你这一轮加的每词每句——划掉它；若句子仍通顺、仍说同一件事，那是 filler——删掉。
- **还原测试（reversion test）**：对你做的每处替换——把原词放回去；若旧写法没问题、且用更少的词说了同样的事，留旧的。

**约束**：本测试不豁免 `zh-fiction/techniques.md` 的 `[必上·换骨]` 条目（它们是故意恢复的，允许存在），但有一个条件——**同一处编辑必须在段落某处删掉了空洞**，且段落结尾不能比开头更长。生成与编辑留下不同痕迹、用不同方式查：架构/表面 Pass 抓生成痕迹；双测试守编辑痕迹。

## 快速检查清单（交付前逐项核查）

- [ ] 禁用词全部替换（见 `zh-fiction/banned-words.md`）
- [ ] 最毒句式：“不是A而是B”“带着……”？直接改
- [ ] 标点违规：冒号、破折号清零；直角引号与半角双引号统一转 `“”`
- [ ] 结构性套话：“让我们来看看”“在当今……的时代”“众所周知”？改
- [ ] 连续同长句：相邻≥3句长度接近？打断一个
- [ ] 段落以有力单句结尾？变换方式，别每段都收得一样
- [ ] 三段式列举？改两项或四项
- [ ] 模糊断言：“意义重大”类空话？说出具体内容
- [ ] 元评论：“本章接下来将……”？删
- [ ] 连接词过度：然而/因此/此外>2处？删
- [ ] 情感告知：“他很紧张”？改动作描写
- [ ] 比喻陈词滥调：如沐春风/梨花带雨？删或白描
- [ ] 教科书开头：“在当今……的时代”？换具体事件切入
- [ ] 走神/糙话/记错/碎对话/不完美角色：至少各一处
- [ ] 对话密度：场景章带引号直接对话≥30%？角色嗓音差异化？对话带冲突？
- [ ] 句式断裂：情绪高点有极短句独立成段吗
- [ ] 连贯性：动机-阻碍-动作-结果链清楚？不OOC？
- [ ] 角色代词一致性：男性角色出现"她/小姑娘"？Agent 并行改稿后强制扫描 + 时间线对表
- [ ] 指纹词换法：替代词每处不重复？热门替代词（冷不丁/莫名/没来由）未用滥？全卷 grep 复查
- [ ] 句号慎重：碎句堆砌或长句连排？句号密度参考每百字 5-8 个，长短交替
- [ ] 电影桥段化：视情境用了镜头感/蒙太奇/台词化对白？（不强行）
- [ ] 减空洞加颗粒：删了空洞修辞？加了生活颗粒？
- [ ] **双测试**：删除测试 + 还原测试跑过？段落未因"加人味"变长？
