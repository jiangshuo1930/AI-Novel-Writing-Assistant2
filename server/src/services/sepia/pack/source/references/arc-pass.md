# 第 4 层 · 卷级：连续几章会不会读腻

前三个 Pass 都在看**一章之内**。可读者是连着看的：今天看三章，明天追两章。

这一层管的是**章与章之间**。很多稿子单章挑不出毛病，连着读三章就困——问题全在这里。

**什么时候跑**：写完一章、准备写下一章之前，拿最近 3–5 章对着看。**只写第一章时跳过。**

---

## 一、钩子别重复

每章的章末都要留一件悬着的事，但**类型要换**。

**先给每章章末打标签**（从下面选一个）：

| 类型 | 长什么样 |
|---|---|
| 危 | 有人或事直接构成威胁："井沿上蹲着个人。" |
| 疑 | 出现一件说不通的事："他数了三遍，都是二十三。可他记得自己给了二十五。" |
| 变 | 关系或身份变了："她叫了他一声哥。" |
| 求 | 出现一个明确要办的事："天亮之前，把人找出来。" |
| 断 | 一句话没说下去，或一个动作做了一半："他推开门，愣住了。" |
| 静 | 事情都平了，但有一处不对（高级玩法，偶尔用）："灯灭了。可窗户上的影子还在。" |

**查法**：把最近五章的标签排成一列。

- 连续三章同一个标签 → 改。
- 五章里只有一到两种标签 → 改。
- 每章都以"危"收尾，读者第三回就知道套路了，第四回开始划走。

**改法**：换一个标签，或者干脆把这一章的收尾往后挪——不结在这一章，把问题留给下一章开头。

---

## 二、高潮位别固定

单章内部，最重的那一下落在什么位置，是有规律的。

**查法**：估一下每章"最重的那一段"在第几成了（一章 2000 字，第 1600 字就是八成）。

- 每章都在八成左右 → 读者会提前犯困，一到八成开始滑。
- 每章都在最后 200 字 → 前面 1800 字都没有着力点，读着像铺垫。

**改法**：
- 让至少三分之一章节的峰值前移（放到四五成），后半段收尾。
- 或者让某一章**没有峰值**——全是小波折，读着轻松，为下一章攒劲。

---

## 三、爽点波形别太规整

网文的节奏是"压—炸—压—炸"。压太短显得轻，炸太密显得假。

**查法**：给每章标一个强度（一星到三星）。

- 一星：低强度，日常、赶路、查访
- 二星：有冲突，但没分出胜负
- 三星：大冲突、翻盘、身份揭露

**合格波形**（示例）：

```
一 二 一 三 一 一 二 三 一 二 三 一
```

**不合格波形**：

- `二 二 二 二 二`：全是二星，读者没有起伏感，也没有持续追读的理由。
- `三 三 三 三`：连炸四章，第五个"爆炸"就不炸了。
- `一 一 一 一 三 一 一 一 一 三`：规律得像钟摆，读者能算出来。

**改法**：三星章之后必须接一个一星章（读者需要喘气），一星章最多连两章。

---

## 四、重复的场景结构

同一个作者，会不自觉地重复同一种"场"。

**查法**：给最近五章每章的结构写一句话：

- 「主角去某处 → 遇到阻碍 → 想办法 → 化解」
- 「主角和人吵架 → 想通 → 行动」
- 「主角被追杀 → 逃 → 反击」

**红线**：连续三章同一个骨架。这是最难发现的一种腻——因为每章单看都不错。

**改法**：换一次骨架。把"去某处"改成"某处的人来找他"，把"想通"改成"没想通就动手了"。

---

## 五、重复的细节与道具

上一章用过的质感细节，这一章别再用一遍。

**查法**：
- 同一件私人物件（某个杯子、某条旧绳）在两章里都承担情绪 → 换一个。
- 同一句口头禅连续出现 → 换说法或减少。
- 同一个动作（摸后颈、搓手指）在五个场景里出现三次以上 → 拆掉一半。

**改法**：人味靠"专属"，不靠"重复"。重复三次的专属会变成另一套模板。

---

## 六、时间线核对

多线并行的故事，最容易在这里翻车。

**查法**：列一条时间轴，标出每章事件的发生时间。检查：

- 一个角色不能同时出现在两个地方。
- 伤势、物资、钱数、天色，要能对上。
- 同一件事，不同人复述时，时间要一致（除非故意让人记错，且后面要交代）。

- [ ] 峰值位置是不是都固定在同一个位置？
- [ ] 强度波形有没有出现全二星或连炸四星？
- [ ] 最近三章的场景骨架是不是同一个？
- [ ] 有没有两章重复使用了同一件情绪道具？
- [ ] 时间线对得上吗？钱、伤、天色、位置？
