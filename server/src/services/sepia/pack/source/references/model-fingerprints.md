# 各模型的写作惯性（中文网文）

不同的生成模型写中文网文，会往不同方向偏。知道自己在用哪个，就提前躲开它的习惯。

这份表是**经验总结**，不是测量数据。模型版本会变，条目也可能过时——用着不对就按你的实际手感改。

---

## DeepSeek（你最常用的）

**最典型的毛病：前置交代。**
故事还没动起来，先把人物来历、世界规矩、前情往事全倒给你。开头三段往往像设定说明。

**其余几条**：
- 叙述人存在感太强，总在告诉读者"这很重要"。
- 情绪全靠动作写，几乎没有内心，读着像在看监控。
- 背景均匀地塞进每一段，像节拍器。
- 喜欢在故事里再讲一个故事。

**怎么改**：
- 砍掉开头那段说明。让背景在跑动中漏出来，一次漏一句。
- 让场景自己转，叙述人退后。
- 加一点口语化的内心，别全写动作。
- 背景别均匀撒，该堆的地方堆，该空的地方空。
- 故事里的故事最多用一次。

---

## Kimi

**指纹最淡，这本身就是问题。**
它什么都可以写得中规中矩，于是什么特征都没有——开头永远从动作中切入，结尾永远收得妥当。

**怎么改**：把它那个"只能有一个"的结构选择用满（见 `narrative-pass.md` 第三节）——换一种进入方式，别让它每次都从"他正在做什么"开始。共享规则要全量套用。

---

## Claude

**最容易被认出来的一个。**

| 惯性 | 怎么改 |
|---|---|
| 冲突升级最平，全程一个力度 | 让压力不均匀地跳：有静场，有突然绷紧 |
| 对文学传统恭敬 | 允许它拿一条成规开个玩笑 |
| 爱用尾声、时间后跳收尾 | 别用尾声，在动作里结束 |
| 完全不用梦境 | 需要时可以用 |
| 气氛老往阴森诡谲上飘 | 换换气氛 |

---

## GPT

| 惯性 | 怎么改 |
|---|---|
| 爱用流言、传闻推动剧情 | 让信息从观察、物件、意外里来 |
| 爱用"多年以后，她会……"这种疏离的回顾腔 | 贴着当下写，别架在几十年后 |
| 反转给得太多 | 别再加反转，把手上这一个做扎实 |
| 关系收得半吊子 | 让一对关系彻底了结，好或坏都行 |
| 人物关系网密但公式化 | 砍到故事真用得上的那几个 |

---

## Qwen

暂按 Kimi 处理：没有明显特征，就全量套用共享规则，并把"只能有一个"的结构选择用满。

## 人写的东西长什么样（可以照着做）

| 特征 | 具体怎么做 |
|---|---|
| 人物在说话或做事时出场 | 第一次出场就在对话或动作里，不标注 |
| 一个视角贯到底 | 深度跟着主角，别跳来跳去 |
| 旁白平时不说话，偶尔来一句 | 不要有系统地插话，零星来一下 |
| 最重的东西放在后面 | 别一上来就把最狠的交代了 |
| 有一个"不寻常"的结构选择 | 换叙述距离 / 换收尾方式 / 掺一点别的类型，**只做一个**（`narrative-pass.md` 第三节） |
| 不甘心只做一个类型 | 在类型里掺点别的东西 |
