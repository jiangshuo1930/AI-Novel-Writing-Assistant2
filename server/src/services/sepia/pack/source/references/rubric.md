# 诊断表 — 网文 28 项体检清单

用来给一章稿子做**结构级体检**。句子层面的问题不在这里查，在 `zh-fiction/` 和 `style-surface.md`。

每一项都写清了三件事：**怎么看出问题、写清楚什么样、怎么改**。不给分数、不给百分比——那是把编辑判断伪装成科学。判断由你下，这张表只负责让你别漏。

---

## 用法（不按这个顺序用就会失效）

1. **分五组看，一次只看一组。** 一趟读完所有项，你的注意力会塌在一两个最显眼的地方，其余全瞎。这是实测过的老毛病。
2. **每个判断必须引原文。** 没有原句，就不算问题。
3. 文本没机会考这一项（没有危险场景 → 谈不上"危机前铺垫"），标 **不适用**，别硬判。
4. 改得过头也是问题。一条本来中性的特征被推到极端（时线打乱到看不懂、干净到没有一个漂亮句子），标 **过度修正**，单独记录，别当成优点。

---

## 第一组：道理讲太多

| 项 | 怎么看出问题 | 怎么写算好 | 怎么改 |
|---|---|---|---|
| 主题点题 | 结尾有没有一段总结"他终于明白……" | 全章不说道理，但读完知道想说什么 | 删总结段，换成动作 |
| 道理比重 | 有没有人物在对话里争论对错、人生、天道 | 吵的是一笔钱、一口气、一个人 | 把辩论改成争具体的东西 |
| 主题统一 | 每个场景、每个意象都在服务同一个意思 | 有一两处纯为好看而存在 | 留一处闲笔，删掉刻意呼应 |
| 旁白评论 | 有没有"人就是这样""说到底……" | 旁白不搭话，或只偶尔来一句 | 删 |
| 对话辩论化 | 关键对话是不是在辩理念 | 对话在推进欲望和冲突 | 重写那场对话 |

## 第二组：情绪只会写体感

| 项 | 怎么看出问题 | 怎么写算好 | 怎么改 |
|---|---|---|---|
| 情绪写法 | 强情绪场景里是不是全靠心跳、冒汗、手抖 | 行为为主，直说其次，体感只留最重的一处 | 大部分改成行为 |
| 环境映心情 | 每场戏环境都在跟着人物心情走 | 天气就是天气，偶尔才映心情 | 删掉"情景同悲" |
| 风景比重 | 景物描写是不是多到拖慢节奏 | 景物只在人物用到它时出现 | 删掉纯布景 |
| 气味使用 | 是不是频繁用气味营造氛围 | 气味省着用，一两处 | 砍掉多余的 |
| 感官密度 | 三样感官并排写的句子多不多 | 中等密度，一次一两样 | 砍掉第三样 |
| 内心深度 | 是不是全程都能听见人物心声 | 大部分外部呈现，关键处才进内心 | 减掉多余的内心独白 |

## 第三组：结构太干净

| 项 | 怎么看出问题 | 怎么写算好 | 怎么改 |
|---|---|---|---|
| 因果链 | 每个事件都由上一件推出，一路无岔 | 中途断一次，或有一条不服务主线的支线 | 切断一环，把原因挪到幕后 |
| 支线 | 完全没有支线 | 网文连载通常有支线；短章可以没有 | 长篇必有一条；短章标不适用 |
| 结局主动权 | 结局全靠主角决定 | 一半时候让运气、别人、规矩决定 | 换一次不由主角做主 |
| 结局形态 | 每章都是"努力→成功→释然" | 可以是失败、半赢、悬着 | 本章赢面别给满 |
| 主角登场 | 第一次出场先写长相身世 | 一上场就在说话或在做事 | 把外貌段删掉或后移 |
| 开场空间交代 | 开头花多少字钉地点 | 一个起作用的细节就够 | 砍到一句 |
| 地点数量 | 全章是否只在一个地方 | 场景比需要多一两个 | 挪一场出去 |
| 危机前铺垫 | 危险来临前有没有先让读者认识这个人 | 先给一点认识，再让他遇险 | 加半段日常 |

## 第四组：人物的"人味"正向项

这些**有就等于加分**，没有不算错。逐条看有没有，别合并算总分。

| 项 | 怎么看出问题 | 怎么写算好 |
|---|---|---|
| 点名真实之物 | 有没有点名真实的书、地名、牌子、物价 | 至少一处点名，且名要对 |
| 旁白偶尔搭话 | 有没有一句"你也见过那种房子" | 一两句，不要元叙事框架 |
| 向读者说话 | 有没有"你看""诸位" | 网文可用，但别每章都用 |
| 具体到能摸 | 关键物件有没有重量、温度、手感 | 每章至少三处 |

> 注意：第四组在**英文文学**里是很强的正向标记，在**网文**里权重低得多——网文读者不吃这套，甚至觉得出戏。本章写得清爽有力，第四组可以全空，不算缺陷。

## 第五组：时间与人物关系

| 项 | 怎么看出问题 | 怎么写算好 | 怎么改 |
|---|---|---|---|
| 时间跳跃 | 是不是从头到尾一条直线 | 至少一处时间错位，且它制造了问题 | 把一段挪成闪回或抢跑 |
| 闪回用法 | 闪回是不是一整段回忆 | 半句就收，不铺开 | 砍到一句 |
| 用时间摆信息 | 有没有用时间差来压信息 | 压住原因先给结果 | 调整叙述顺序 |
| 翻案后重读 | 一处揭晓能不能让前文换个意思 | 能 | 加强前面的伏笔 |
| 对话比例 | 有两人在场的章节，对话占比多少 | 三成到四成半 | 低于两成要加对话 |
| 对主角的道德立场 | 是不是明确肯定或明确谴责 | 暧昧，或"事上赢了做法错了" | 给主角一个不体面的动机 |

## 报告格式

```
网文体检 — 《章节名》
第一组 道理讲太多：<项> — <引文>；…；不适用 <项>
第二组 情绪体感：<项> — <引文>；…
第三组 结构太干净：<项> — <引文>；…
第四组 人味正向项：<有/无> — <引文>
第五组 时间与关系：<项> — <引文>；…
过度修正：<项> — <引文>
最深的问题（先改这个）：<一句话>
计划：<按结构→篇章→句子的顺序排，每条绑一句原文>
```

> 与表面层的对接：这里的结论直接决定上哪几招。第三组"因果链太顺"→ 上第 19 招干扰项；第二组"情绪全靠体感"→ 上第 16 招行为化 + 第 21 招感官偏见；第一组"主题点题"→ 删末段（第 30 招减空洞）。**不要**跳过这一层直接堆技法。
