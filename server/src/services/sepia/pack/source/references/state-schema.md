# 跨章状态台账（state.md）

写长篇最大的麻烦不是这一章写得不好，是**上一章的东西忘了**。

写到第七章，第一章那个"二十三枚铜板"早没影了；写到第十章，某个配角的手已经好了，但你还写他捂着；写到第十五章，伏笔埋了七个，收了两个，剩下五个你自己都不记得。

这就是台账的用处。**不是给读者看的，是给自己（和下一次写作）看的。**

---

## 放在哪

```
books/
  书名/
    ch001-章节名.md
    ch002-章节名.md
    ...
    state.md          ← 这里
```

每写完一章，更新一次 `state.md`。每写新章之前，先读一遍。

---

## 模板（照抄，别自创格式）

```markdown
# 《书名》状态台账

最后更新：第 N 章之后

## 一、时间与位置

| 项 | 现在是什么样 |
|---|---|
| 故事内时间 | 第 X 夜 · 丑时（距天亮还有约一个半时辰） |
| 主要人物在哪 | 沈昭：雾巷口井边 · 苏九娘：闻墨斋内 · 老陈头：不明（午后出城未归） |
| 天色/天气 | 雾浓，能见度三步 |

## 二、人物持有物

| 人物 | 手上有什么 | 欠别人什么 | 别人欠他什么 |
|---|---|---|---|
| 沈昭 | 无字之书（怀内）· 灯笼 ‹一盏› · 二十三枚铜板 + 半吊碎银 | 苏九娘三吊钱 | 苏九娘双倍工钱未结 |
| 苏九娘 | 算盘 · 三箱书（货） | — | 沈昭三吊 |

> 数字要写具体。写"一些钱"等于没写。

## 三、人物状态

| 人物 | 身体 | 心态 | 已知什么 / 不知道什么 |
|---|---|---|---|
| 沈昭 | 右手食指割伤（浅） | 怕，但已经出门了 | 知道自己能看见死期；不知道书的来历、不知道死者是谁 |
| 老陈头 | 未知 | 未知 | 未知（本章未出场） |
| 老王头 | 正常 | 心虚 | 似乎知道沈昭哥哥的事，但不说 |

## 四、伏笔台账

| 编号 | 内容 | 埋于 | 状态 |
|---|---|---|---|
| H1 | 黑影是人形，会"催"人出门 | 第1章 | 未回收 |
| H2 | 老陈头午后出城收账，未归 | 第1章 | 未回收（可能是干扰项） |
| H3 | 血渗进书页，字才长出来 | 第1章 | 已回收（启动条件） |
| H4 | 城西义庄门口的一整排门板 | 第1章 | 未回收 |
| D1 | 老王头说"你哥那年也是这么走进去的"，随即否认 | 第1章 | **干扰项，永不回收** |

> **规矩**：伏笔只能用台账里已有的编号推进。要新增，先查有没有相似的（同一件事换个说法埋第二次，读者会觉得你忘了）。

## 五、未解决的事（下一章要接的）

1. 井沿上蹲着的是谁，活着吗
2. 丑时三刻还有一刻，来得及吗
3. 苏九娘会不会发现他半夜出门
4. 老陈头到底回没回

## 六、本章新增的可复用细节

- 沈昭习惯：紧张时数钱
- 苏九娘的账：去年冬天欠三吊，上个月已从工钱扣过一次，账还在
- 井沿：青石砌，缺了一角
- 城西义庄：门口摆一整排门板

> 这一栏是为了让后面几章能"回扣"。一个细节用过一次就扔，读者感觉不到这个世界是真的。
```

---

## 用法（三条，不多）

**写前**：读一遍第三节和第五节。知道人物现在在哪、身上有什么、上一章留了什么。

**写后**：更新第一、二、三、四节。第五节重写（旧的勾掉，新的写上）。

**每十章**：通读第四节。超过八个未回收伏笔，说明埋得太散，该收两个了；有三条以上"忘了要干什么"的，直接标死，别再惦记。

---

## 一条硬规矩

**台账里的数字必须和正文对得上。**

正文写"二十三枚铜板"，台账就写二十三。下一章花了五枚，台账改十八，正文也得写十八。

这条最容易松。而读者对数字最敏感——他们真的会数。
