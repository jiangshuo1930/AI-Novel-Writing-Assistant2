# 第 3 层 · 句子：改到读着像人写的

最后一层。前面两层没做对，这一层改得再细也没用。

**改稿的方向**：以替换为主，删为辅，加最少。文本变长只有一种正当理由——**具体了**。修补不是增长。

---

## 一、七类毛病（按出现频率排）

| # | 毛病 | 怎么改 |
|---|---|---|
| 1 | **词用得别扭**（最多） | 换掉错位或书面腔太重的词。"似乎/仿佛+动词"直接换成动词，除非人物真的不确定。含糊的代词、多余的"被……所"理清 |
| 2 | **句子缠在一起** | 一个逗号连到底的长句，拆成两句。一个缠住的念头，就该是两个平白句 |
| 3 | **说了等于没说** | 场景已经暗示的东西再讲一遍，删。典型句式："月光把荒原照得惨白，孤零零地笼罩着无人的旷野"→留前半句 |
| 4 | **陈词滥调** | 换成贴这个场景的新说法。**别换成更平淡的同义句**——那是换了个方式的失败。想不出新鲜的，就删掉这句 |
| 5 | **不够具体** | 这一项是加：真名、物件、数字、生活里的小动作。没素材就问作者。填一个更笼统的描述只会更糟 |
| 6 | **华丽空转** | 一串抽象名词只为一个感觉服务，砍短。"她哭了。哭的是不公平。哭完什么也没换来。"比"她的泪水承载着对命运不公的控诉"强 |
| 7 | **视角或时间漂移** | 钉住叙述人和时间参照，搜段落里"此刻""那天"混跳的地方 |

## 二、句式模板（见了就拆）

| 模板 | 例子 | 怎么拆 |
|---|---|---|
| "一种……的感觉" | 一种说不清的疲惫感 | 说出具体是什么，或删掉这层包装 |
| "在……之中 / 在……的过程里" | 在漫长的等待之中 | 直接说发生了什么 |
| 句尾挂件："，带着……""，仿佛……""，像是在……" | 他推开门，带着一身寒气，仿佛刚从雪里走出来 | 断成有主谓的短句 |
| 动作变名词当主语 | 那一刻的醒悟、那种决断 | 变回动词：他忽然明白了 |
| 成对抽象"X与Y" | 恐惧与希望交织 | 留一个 |
| "不是X，而是Y""不禁……""不仅……而且……" | — | 说你真正想说的那一件 |
| 三的法则 | 三处并列，满篇都是 | 用两样或四样，打破节奏 |

> 中文完整清单（替代词、句式黑名单、道具黑名单）在 `zh-fiction/banned-words.md`。

## 三、该加回来的人味（机器被训练得不这么写）

按题材和人物嗓音的程度，**撒，不是倒**：

- 口语缩略：啥、咋、甭、别（古风不用网络口语）
- 口头填充：反正、就、其实、也说不上、你别说
- 平白连接：因为、所以、结果、这才（别用"因此""于是乎"）
- 含糊与强调：大概、八成、还真、确实
- 口语否定：谁说不是、也没、压根没
- 平白提示语：说、问、答、喊（别轮着用"低声道""缓缓开口""意味深长地说"）
- 第一二人称、直接问句（视角允许时）
- 粗话、直白话（语域真需要时）

**加不等于灌水。** 改稿收尾前跑两个测试：

- **删除测试**：这一轮你加的每个词每句话，划掉它。句子还顺、意思没变，那就是水，删。
- **还原测试**：你替换的每处，把原词放回去。旧写法没问题、还更短，留旧的。

修补性的改动（坏句要的主语、拆长句补的标点、名词化还原要的动词）过不了这两个测试也该留——那是修，不是加。上面那些是**故意**加回来的，只要满足一个条件就行：同一处必须顺手删掉了水，且段落末尾不比开头长。

## 四、句长节奏

机器写的句子，长短差得不远。

**查法**：找相邻、长度接近的句子串，连续三句以上一个方向就算（三和"接近"是阅读习惯，不是铁律）。这只是**候选**，要跟别的毛病一起算，别单凭它下判断。**不要**拿长短阈值给段落打分。列表、设定表、标题没有节奏可测，直接跳过。

**怎么破**：靠**挪词**，不靠加词。拆一句长的、并两句短的、删一个从句。往哪边破看文本——长句串里塞一句短的，短句串里接一句长的。别一律砍短，通篇短句是换个方向犯同样的错，读起来像模仿。

---

## 五、朗读测试

语法对但念不出来，是独立的一种毛病。

把改过的句子和所有对话出声念一遍。没有中文读者会那么说、人物不会那么开口的，用口语的形状重写。**网文尤其吃这条**——对话念着不像人话，读者当场出戏。

---

## 六、哪些不算毛病（过度修正本身就是新的假）

- 干净的语法和标点。很多人写得也干净，故意弄得糙是可识别的花招。
- 单个破折号、分号、生僻词。单次命中没意义，成群才算。
- 正式庄重的语域。该正式就正式，别为了显随意硬加口语。
- 角色说脏话、说官腔、说错话。那是人物，保留质感。
- 作者自己惯用的词。你爱用就用。
- 平常的过渡句。人是松紧交替的，不必每句都精彩。
- 标点密度、段数、平均段长本身。只有**段内长短均匀**才是信号。
