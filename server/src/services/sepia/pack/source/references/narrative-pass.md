# 第 1 层 · 架构：人物的欲望与事件的因果

这一层管的是**结构**：这一章要发生什么，为什么发生，读者为什么想往下看。句子怎么写放到最后。结构错了，改词救不回来。

不引任何外部研究。网文的规矩就是读者的规矩，下面每一条都能在手机上验证：读着困就是错了。

---

## 一、架构表（写前必填，写完当自检清单）

| 项 | 填什么 | 合格线 |
|---|---|---|
| 本章主角想要什么 | 一件具体的、这一章内能动手去争的东西 | 不能是"变强""活下去"这种空话 |
| 阻碍 | 谁或什么挡着，为什么挡 | 必须有具体的人或规矩，不能只是"很难" |
| 他做了什么 | 至少一个可见的动作 | 不能只"想了想" |
| 结果 | 事情变成什么样 | 必须有变化，不能原地踏步 |
| 本章的实质变化 | 位置/持有物/认知/关系，四选一 | 至少一项 |
| 章末悬着的事 | 一件具体的、没解决的事 | 不能是"未来会怎样" |
| 信息给的时间点 | 哪条信息压到后面给 | 至少一条 |
| 出场人物之间的关系 | 谁和谁有旧账、谁看谁不顺眼 | 不能人人对主角好 |

## 二、七组检查

### 组 1｜主题别说出口

**问题**：作者跳出来总结道理，人物在对话里辩论人生。
**长什么样**：结尾一段"他终于明白，人这一辈子……"；两个人吵架吵的是"什么是对错"而不是"这钱该谁出"。
**怎么改**：删掉总结段。把辩论改成争具体的东西——争钱、争面子、争一口气。想表达的意思，让事件自己说。
**合格**：整章没有一句"道理"，但读完知道作者想说什么。

### 组 2｜情节别走单轨

**问题**：每个事件都由上一件引出，一条线笔直到结尾，中途没有任何岔子。
**长什么样**：主角查一件事，线索一二三依次到手，最后真相大白。
**怎么改**：
- 至少有一条支线不完全服务主线（家事、旧账、闲人）。
- 允许因果断一次：一件事没来由地发生，或者后果从别处来。
- 埋一个永不解释的细节。真事里有说不清的东西。
- 让主角猜错一次方向。
**合格**：读者能指出至少一处"这事跟主线没关系，但有意思"。

### 组 3｜结局别太圆

**问题**：主角努力→成功→释然，三步齐全，每章都这样。
**长什么样**：每章末尾主角都有所领悟。
**怎么改**：安排一次失败，或者赢了一半。让外力（运气、别人、规矩）决定结果，而不是全靠主角聪明。章末可以停在"事情没完"上。
**合格**：本章的赢面不是满分。

### 组 4｜时间别一条直线

**问题**：从头讲到尾，一刻不停，没有回望也没有抢跑。
**长什么样**：流水账。
**怎么改**：用时间跳来摆信息。压住原因，先给结果，读者会追着问为什么。闪回只闪半句就收，别整段回忆。
**合格**：本章至少有一处时间错位，且它制造了问题。

### 组 5｜情绪别只会体感

**问题**：一写到害怕就是心跳、冒汗、手抖；一写到愤怒就是攥拳。
**长什么样**：所有情绪都化成同一套生理反应。
**怎么改**：情绪有四种写法——行为、直说、体感、含混。行为最好用，直说最省事（"他怕了"是人会写的句子），体感留给最重的那一下，别处别用。环境别跟着人物心情下雨。
**合格**：本章的强情绪场景里，体感不超过一处。

### 组 6｜人物别太齐整

**问题**：好人全好，坏人全坏；反派孤家寡人专门跟主角作对；人物一出场先交代长相身世。
**长什么样**："他身材高大，面容冷峻，是城里最强的高手。"
**怎么改**：
- 主角第一次出场就让他说话或做事，别先写外貌。
- 好人要有私心，坏人也得有个在乎的人。
- 反派人缘要好——他有手下，有朋友，有自己的圈子。
- 配角要有和主角无关的生活。
**合格**：本章里至少两个人做过一件和立场矛盾的事。

### 组 7｜信息别一次性给完

**问题**：关键信息靠一个人坐下来从头讲到尾，或者靠一封信、一份档案、一次搜索。
**长什么样**："其实当年的事是这样的……"然后三百字。
**怎么改**：把真相打碎成五到七片，散在日常里。前两三片要以无关细节的样子出现，读者第一遍看不出来。最后让主角自己拼出来，别让人告诉他。
**合格**：本章没有超过三行的解释性独白。

## 三、那个只能有一个的动作

人类写的东西有一种"不寻常"。二十个人拿到同一个开头，会写出二十种不同的走向；机器写出来的，二十种里有一半撞车。

所以每篇只做一个**对本故事不寻常**的结构选择：换一个叙述距离、用一个这个类型很少用的收尾方式、或者在类型里掺一点别的类型的东西。

只能一个。做两个就显得在表演。

## 四、自检（写完对着看）

1. 第一屏出事了没有？
2. 主角这一章想要什么？说得出来吗？
3. 阻碍是具体的人还是空话？
4. 结果有变化吗？变化可追踪吗？
5. 章末悬着的是什么事？能一句话说出来吗？
6. 有没有一处"这事跟主线无关但有意思"？
7. 主角有没有一处判断错了？
8. 有没有两个角色做过和立场矛盾的事？
9. 关键信息是怎么给的？有没有一大段解释？
10. 最重的情绪那一下，是用体感写的还是用行为写的？
